## Recurring patterns and bounded fixes

Exact grounding rejects singular/plural forms, copied attribute variants (mesh material vs mesh), intended-use plurals, and limited product aliases. The change uses bounded lexical equivalents and original-wording recovery, not fuzzy category matching. Missing optional preferences remain nonblocking. Numeric not exceeding must be masked from exclusion checks only after successful numeric parsing; genuine negations and parser issues still gate.

HELD007 illustrates semantic-equivalence differences: mesh material was rejected while mesh occurs literally, and lumbar support differs from the label with lumbar support. HELD011 preserves at least 1500 watts while the label says 1500 watts; removing the operator merely to improve exact F1 would lose meaning. HELD013 labels no preferences for unsupported milk, while the extractor copies fresh/organic; this is a policy/annotation disagreement on an already gated query. Those labels remain unchanged.

New live outputs are not perfectly deterministic: the repeated P0 regression run extracted leather as a wallet brand in HELD018, unlike the historical null sentinel. The provisional set then exposed handmade as a manufacturer (F015) and an arbitrary scalar Nike under competing brands (F044). These are genuine safety defects, not label wording differences. Two focused tests failed before correction (`brand_failures_before_fix.txt`); the final safety revision removes unverified attribute-derived manufacturers, asks for clarification, and clears scalar brand under competing-maker ambiguity. All initial results and freezes are retained.

The final revision is a post-provisional repair. It invalidates any claim that the provisional set remains independent. No human reviewer has approved either the new labels or the semantic correction decisions. Source-grounding is not a complete named-entity or injection defense.
